# Instruções Base para IAs (Agents)

Este documento define as diretrizes de comportamento e conhecimento para agentes de IA que operam neste repositório.

## Princípios
1. **Confiabilidade:** Sempre priorize a integridade dos dados e a observabilidade.
2. **Rastreabilidade:** Toda alteração deve ser mapeada para um requisito ou risco identificado.
3. **Padrões SRE:** Utilize práticas modernas de SRE (Error Budgets, SLIs, SLOs).

## Fluxo de Trabalho
Os agentes devem seguir o ciclo: **Research -> Strategy -> Execution**, validando cada etapa contra os requisitos definidos em `documents/`.
